# Brass Knuckles Mod

Adds custom Brass Knuckles animations to Minecraft Bedrock for Android.

## Features

- Custom Brass Knuckles animations for Minecraft Bedrock for Android
- Multiple punch animations including Left/Right Punch, Alternating Combo, Double-Fist Smash, Uppercut, and Hoo

## Requirements

- Minecraft Bedrock Edition 1.26.52 for Android
- Forge Mod Loader

## Installation

1. Download the mod from the releases page.
2. Place the mod file in the `mods` folder of your Minecraft Bedrock Edition installation.
3. Launch Minecraft Bedrock Edition and enable the mod in the settings.

## Usage

- The mod will automatically load custom Brass Knuckles animations when you join a world.
- Use the `/brassknuckles` command to access mod commands.

### Commands

| Command | Description |
|---------|-------------|
| `/brassknuckles` | Displays the Brass Knuckles Mod commands. |
| `/brassknuckles reload` | Reloads the animations. |

## Configuration

The mod does not have a configuration file. All animations are hardcoded and cannot be modified.
